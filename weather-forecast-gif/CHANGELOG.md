# Changelog

## 2026.09.30.0

- Add `cartodb_api_key` option to authenticate the radar basemap tile requests, which CARTO now requires

## 2026.09.10.0

- Add human-readable names and descriptions for the configuration options in the add-on Configuration tab

## 2026.09.09.1

- Add `show_time` option to hide the time in the header, leaving only the date and day of week
- Add `date_format` option to configure the header date (e.g. `MM-DD`, `DD.MM.`, `MM/DD`)
- Add `time_format` option to choose between 12-hour and 24-hour clock display
- Apply the time format to the radar map's per-frame timestamps, including AM/PM in 12-hour mode

## 2026.07.27.0

- Add rain-chance bars: per-day precipitation probability indicators on the forecast row and a full-height bar in the current conditions section

## 2026.04.23.0

- Improve API Error fallbacks and gif generation

## 2026.04.19.1

- Improve README's

## 2026.04.19.0
